# 뭐바를래 관리자 페이지 전체 QA 점검표

- 대상: `/admin`
- 작성일: 2026-07-23
- 기준: `docs/QA/QA.md`의 점검 형식, 실제 프론트·백엔드 코드, 관리자 API 계약과 테스트
- 범위: 관리자 접근 제어, 공통 레이아웃, 현재 관리자 메뉴 9개, 모바일·접근성, 오류·보안·성능, 고객 화면 회귀
- 상태 표기: `✅ 통과` · `❌ 실패` · `⚠️ 확인 필요` · `⬜ 미실행`
- 진행 방식: 1차 `localhost` 전체 기능 QA → 2차 `mubarelle.com` 배포 smoke QA

> 이 문서는 QA 실행 전 체크리스트다. 실행 결과는 각 항목의 `[ ]`를 `[x]`로 바꾸고, 뒤에 상태·근거·실행일을 기록한다.
>
> 현재 `mubarelle.com` 관리자 권한을 부여할 수 없는 동안에는 `localhost:5173`에서 실제 로컬 API·DB를 연결해 1차 QA를 진행한다. 로컬 통과는 기능 검증 결과이며 운영 배포 최종 통과를 뜻하지 않는다.
>
> 배포 관리자 권한이 준비되면 HTTPS·쿠키·CORS·reverse proxy·배포 환경변수·RDS·S3/CloudFront·Elasticsearch를 중심으로 2차 smoke QA를 실행한다.
>
> 상품·가격·재고·성분·이미지·주문·결제·클레임을 바꾸는 항목은 전용 QA 데이터와 팀 승인 후 실행한다. 운영 데이터로 상태 변경 테스트를 하지 않는다.
>
> 대량 등록·이미지 연결·성분 판정은 부분 성공할 수 있다. 응답 확인 실패를 저장 실패로 단정해 같은 요청을 바로 반복하지 말고, `import_sku`·상품 코드·판정 이력으로 실제 반영 여부를 먼저 확인한다.

## 0. 문서 적용 범위

현재 `/admin`은 하나의 라우트 안에서 사이드바 메뉴로 화면을 전환한다. 이 문서에서는 아래 메뉴 각각을 한 페이지로 취급한다.

1. 대시보드
2. 상품 조회/상태 확인
3. 상품 등록/수정
4. 엑셀 상품 대량 등록
5. 이미지 대량 연결
6. 성분 매핑 검수
7. 재고/가격 확인
8. 주문 상태 확인
9. 취소·클레임 관리

`EvidenceCandidateReviewPanel`은 코드에는 있으나 현재 `/admin` 메뉴나 라우트에 연결되지 않았으므로 이번 체크리스트에서 제외한다. 관리자 계정·권한 관리와 감사 로그 화면도 M-Auth 후속 범위라 현재 페이지 QA에서 제외한다.

## 1. QA 실행 정보와 사전 준비

### 단계별 진행 원칙

#### 1차 — localhost 전체 기능 QA

- 대상 프론트: `http://localhost:5173/admin`
- 대상 API: `http://localhost:8000/api`
- 데이터: 로컬 PostgreSQL 및 로컬 연동 서비스

#### 2차 — mubarelle.com 배포 smoke QA

- 대상 프론트: `https://www.mubarelle.com/admin`
- 데이터: 배포 환경의 승인된 전용 QA 데이터
- 범위: 배포 접근 권한, HTTPS 세션 쿠키, CORS, reverse proxy, 빌드 환경변수, RDS migration, S3/CloudFront, Elasticsearch, 직접 URL 접근과 새로고침, 실제 네트워크 성능

- [ ] 로딩 화면·목록·상세에 적절한 `aria-busy` 또는 상태 안내가 있다.
- [ ] 성공 안내는 `role="status"`, 치명적 오류는 `role="alert"`로 전달된다.
- [ ] 색상 배지만으로 성공·경고·실패를 구분하지 않고 텍스트 라벨이 함께 있다.
- [ ] 포커스 표시가 모든 링크·버튼·행·입력·선택기에서 보인다.
- [ ] 클릭 가능한 표 행을 키보드로도 선택할 수 있다.
- [ ] 검색형 선택기의 위·아래·Enter·Escape·Tab 동작과 선택 상태가 올바르다.
- [ ] 확인·정보 모달이 열리면 포커스가 내부에 갇히고 Escape 정책이 일관된다.
- [ ] 모달을 닫으면 실행한 버튼으로 포커스가 돌아간다.
- [ ] 처리 중 닫을 수 없는 모달은 그 이유와 진행 상태를 보조기기에 알린다.
- [ ] 인라인 오류가 관련 입력과 `aria-invalid`·`aria-describedby`로 연결된다.
- [ ] 이미지 미리보기에 의미 있는 대체 텍스트가 있고 장식 이미지는 중복 낭독되지 않는다.

## 17. mubarelle.com 배포 smoke QA

- [ ] 관리자 계정으로 로그인한 뒤 `https://www.mubarelle.com/admin`에 접근할 수 있다.
