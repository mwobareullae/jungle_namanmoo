# 뭐바를래 근거(논문) 정책 — evidence-policy

> 지금까지 여러 파일에 흩어져 있던 "논문을 무엇에 붙이고 / 어떻게 모으고 / 어떻게 고르고 / 어떻게 점수에 반영하는지"를 한곳에 모은 정본 문서입니다.
> 통합 출처: `기능명세서_12고민반영`, `12고민 36편 배경논문`, `30성분 90편 배경논문`, `성분_피부고민_연결논문`, `22성분 evidence_v5 score_use_rules`, `스코어링_마스터`, `regulatory_screen_v1`, `concentration_to_score_v2`, `product_clean_score_formula_v1`.
> §1~§4는 기존 파일에 **이미 있던** 규칙을 모은 것이고, **§5(새 논문 처리)만 지금까지 문서에 없던 신규 규칙**입니다.

---

## 한눈에

논문은 **성분 × 효능축**에 대해서만 다룬다. 사용자 입력은 **표준 피부고민 12개**로 받고, 점수는 그 12개가 매핑되는 **6개 점수축**에서 계산한다. 출처는 **PMID/PMCID/공식 URL만** 인정하고, 대표근거는 **성분당 3편**을 유지한다. 논문은 "성분의 자격"을, 함량은 "제품에서 그 효과가 실현될 가능성"을 증명한다.

---

## 1. 범위 — 논문을 무엇에 대해 다루는가

### 1.1 2층 구조: 표준 피부고민 12개 → 점수축 6개

사용자에게는 12개 고민을 보여주고, 내부 점수는 6개 축에서 낸다. (정본 = `기능명세서 ▸ 표준피부고민_12` 시트. 미해결결정 #12에서 "12개 concern_id로 락, 15~20개 브레인스토밍은 폐기" 확정)

| concern_id | 표준 피부고민 | 매핑 점수축 |
|---|---|---|
| C01 | 미백/색소침착/잡티 | 미백축 |
| C02 | 여드름/트러블 | 여드름·피지축 |
| C03 | 주름/탄력 | 주름축 |
| C04 | 건조/수분부족 | 보습·장벽축 |
| C05 | 피부장벽 손상 | 보습·장벽축 |
| C06 | 민감성/자극/홍조 | 진정축 |
| C07 | 가려움/아토피성 | 보습·장벽축 + 진정축 |
| C08 | 각질/피부결 | 각질축 |
| C09 | 모공/블랙헤드 | 여드름·피지축 *(지표 차용)* |
| C10 | 피지과다/유분 | 여드름·피지축 |
| C11 | 흉터/여드름 자국 | 미백축 + 진정축 보조 *(함몰 흉터는 점수 제외)* |
| C12 | 톤 불균형/칙칙함 | 미백축 + 각질축 *(지표 차용)* |

**점수축 6개:** 미백 · 여드름/피지 · 주름 · 보습/장벽 · 진정 · 각질
- 새로운 "재생축"은 만들지 않는다. 흉터는 PIH(색소자국)=미백축, PIE(홍반자국)=진정축 보조, 함몰 흉터=점수 제외.
- 표준지표가 약한 축(모공·흉터·톤)은 유사 축 지표를 차용하고 `측정표준화_약함=Y`로 표시 → 나중에 효과크기 신뢰도를 보수적으로 본다.

### 1.2 논문이 붙는 단위 — 두 종류를 섞지 않는다

| 종류 | 무엇 | 규모 | 용도 |
|---|---|---|---|
| **성분 자체 대표논문** | 성분 하나의 대표 근거 | 30성분 × 3편 = 90행 | 성분 기본 설명 · effect_strength 후보 |
| **성분×고민 연결논문** | "이 성분이 이 고민에 효과"의 근거 | 성분-축별 | 성분→고민 점수 직접 반영 |
| *(배경)* 피부고민 배경논문 | 고민의 정의·기전·측정지표 | 12고민 × 3편 = 36행 | 점수화 아님. 측정지표(MASI/TEWL/lesion 등) 기준 잡기용 |

> "성분 자체 근거"와 "고민 연결 근거"는 선정 기준이 다르므로 섞지 않는다.

## 2. 수집·검증 규칙

**출처 자격:** PMID / PMCID / 공식기관 URL만 인정. (PubMed, Cochrane, 식약처(MFDS), AAD, CIR 등) → 블로그·판매페이지·브랜드 주장은 제외.

**검증 방법(Citation Verification):** PubMed/PMC에서 PMID를 **실제 조회**해 제목·연도를 대조한다. 제목이 축약/표기 차이가 있으면 `CHECK`로 보수 표시.

**검증 상태 플래그:** `PMID_VERIFIED` (제목·연도 MATCH) · `PMID_FOUND_TITLE_ABBREVIATED_CHECK` (PMID는 확인, 제목 수동확인) · `OFFICIAL_URL` (고시·공식자료) · `보강_웹확인` (웹 확인, PMID 스크립트 재검증 예정).

## 3. 대표근거 선정 규칙

선정은 **두 층의 5순위 기준**으로 하고, 실제 적용은 **선별 퍼널**로 순서대로 거른다.

### 3.1 성분 자체 대표논문 — 5순위 (`30성분 90편 ▸ 선정기준`)
1. **성분명 직접성** — 단일성분/명확한 성분군 > 복합제형·혼합
2. **연구유형** — 가이드라인/SR/RCT/사람 임상 > 세포·동물·제형
3. **화장품 적용성** — 국소·OTC·저농도 > 경구·주사·의약품 고농도·필링
4. **출처 검증** — PMID/PMCID/공식 URL만
5. **대표성** — 3편 중 하나는 리뷰/개관 우선

### 3.2 성분×고민 연결논문 — 5순위 (`연결논문 ▸ 선정기준`)
1. **고민 직접성** — 그 성분의 그 고민 효과를 실제로 측정한 논문
2. **측정지표 존재** — MASI·TEWL·피지·주름% 등 객관 지표 (주관 만족도만 있으면 강등)
3. **화장품 적용성**
4. **연구유형** (가이드라인>메타>RCT>임상)
5. **단일/복합 구분** — 복합제는 단독효과로 쓰지 않고 비고 표시

### 3.3 선별 퍼널 — 실제 거르는 순서 (`v5 ▸ 논문선별기준`)
`1차` 피부고민 축 관련성 → `1.5차` **도포·농도·성분형태 일치**(바르는 화장품 맥락인가) → `2차` 연구유형 → `3차` 공식 출처 검증가능성 → `4차` 동점자 비교(인용수·저널·최신성·표본수)

> 핵심 원칙: **인용수보다 근거위계(EBM)와 화장품 적용성을 먼저 본다.** 인용수는 동점일 때만 쓴다.

## 4. 논문 → 점수 반영 규칙

### 4.1 근거 신뢰도 `evidence_trust` — 연구유형으로 자동 부여 (`v5 ▸ 산출규칙`)

눈대중 소수점을 없애고 연구유형으로 방어 가능한 값을 준다.

| 연구유형 | evidence_trust | 등급 |
|---|---|---|
| 가이드라인 / 식약처 / Regulatory | 0.95 | A |
| 메타분석 / 체계적문헌고찰 / Cochrane | 0.90 | A |
| RCT / double-blind / controlled | 0.85 | A |
| 일반 임상 | 0.80 | B |
| 일반 리뷰 | 0.75 | B |
| 안전성 평가 / CIR | 0.60 | C |
| 세포 / 동물 / in vitro·vivo | 0.45 | C |

### 4.2 근거 사용 등급 `score_use_level` — 강등조건·하드규칙 (`v5 ▸ score_use_level규칙`)

행마다 감으로 정하지 않고 조건으로 산출한다. 기본은 **주점수**, 조건에 걸릴 때마다 한 단계씩 강등.

- **강등조건 (각 1단계):** `route_mismatch`(주사/경구/시술/필링) · `concentration_mismatch`(고농도·의약품) · `indirect_or_complex_formula`(복합제·regimen) · `non_pubmed_source_check`
  - 0개 → **주점수** / 1개 → **보조점수** / 2개 이상 → **참고만**
- **하드규칙 → 무조건 참고만:** `preclinical_only`(세포·동물·기전) · `safety_only`(CIR 안전성) · `pdrn_topical_evidence_limited`
- **예외 → 주점수 가능:** 식약처 기능성 고시 성분 (아데노신 주름개선 등, 법적 기능성 근거)

### 4.3 점수 공식에서의 위치 (`스코어링_마스터 ▸ 점수공식_정의` — 곱셈 구조)

| 단계 | 공식 | 무엇을 반영 |
|---|---|---|
| 1. rule_weight | effect_strength × evidence_trust | 효과 크기 × 근거 신뢰도 |
| 2. 조정 rule_weight | × applicability × regulatory | 적용성 · 규제 |
| 3. 성분기여점수 | × 함량점수 × 함량신뢰도 | 제품 함량 (성분 단위) |
| 4. 개인민감보정 | 제품점수 × 개인민감보정 | 민감/안전 별도 곱(효능과 분리) |
| 5. 제품 클린점수 | 주70/보조30 그룹 noisy-OR, cap 100 | 제품 단위 축별 점수 |

> **신뢰도 산정 원칙:** "근거가 강하다"와 "효과가 크다"는 다르므로 evidence_trust와 effect_strength를 분리한다. 고시 성분은 연구유형이 아니라 고시로 신뢰도를 매긴다.

## 5. 새 논문 처리 규칙 — 도전자 방식 ⭐신규

> 지금까지 문서에 **유일하게 비어 있던** 규칙. 아래는 이번에 확정한 내용.

- **보유는 영원히 성분당 3편.** DB는 무한정 커지지 않는다.
- 새 논문은 대표 3편 중 **가장 약한 1편의 도전자**로 들어온다.
- **비교 기준 = §3 선정 기준 재사용**, 순서대로: ① 연구유형(등급) → ② 성분 직접성 → ③ 화장품 적용성 → ④ 동점 시 최신성·표본수
  - 도전자가 앞서면 → **교체** (새것 IN, 제일 약한 대표 OUT)
  - 못 미치면 → **폐기** (홀드하지 않음. 나머지 탈락 논문과 비교할 필요 없음)
- **자동으로 두면 사고 나는 2가지는 사람 승인 후에만 반영 (안전핀):**
  1. **방향이 반대인 새 논문** — 기존 3편과 효과 방향이 반대인데 등급이 높게 나오면 (예: "효과 없음" A급 RCT) → 검토 큐
  2. **근거 등급이 바뀌는 교체** — 교체로 evidence_trust/rule_weight가 실제로 변하는 경우 → 승인 후 반영
- 나머지(수집·PMID 검증·등급 판정·약한 논문 폐기)는 자동으로 돌려도 된다.

**파이프라인 초안:** PubMed 주기 수집(성분명+효능축 키워드) → PMID 실재 검증 → 등급·직접성·적용성 자동 판정 → 대표 3편과 비교 → (교체후보/검토큐/폐기) → 교체 시 근거계수 재계산 → 사람 최종 승인. 승인 화면은 관리자 페이지의 **성분 매핑 검수** 메뉴에 붙일 수 있다.

## 7. 열린 항목 / 확인 필요

1. **점수 공식 — 2층 구조 (상충 아님, 통일할 건 안전·스케일)** — 효능 산출은 **곱셈**(스코어링_마스터: es×et×적용성×규제×함량×함량신뢰도 → 제품 noisy-OR), 최상위 총점은 **가중 가산**(기능명세서 ⑦: 성분효능×0.45 + 성분근거×0.35 + 피부타입×0.15 + 가격×0.05 − 위험감점). 층이 다르므로 상충은 아니다. 다만 안전을 감점(⑦)으로 볼지 곱(마스터 개인민감보정)으로 볼지, 그리고 두 층의 스케일(0~1 ↔ 0~100) 정합만 확정하면 된다. 자세한 공식은 `scoring-design.md` 참조.
2. **웹 보강 논문 재검증** — `보강_웹확인` 행(코직2% RCT, 알란토인 6% Phase3, Zinc PCA 1% 등)은 PMID 스크립트로 재검증 예정.
3. **근거 약한 성분 정직 표시 유지** — 스쿠알란·디메치콘(주의), 알란토인 등(약함, C급 비중 큼)은 과장 없이 보조로만.
4. **effect_strength 초안값** — 현재 초안이며 함량 기준·실제 효과크기 확인 후 다음 버전에서 수정.
5. **DB 적재** — 위 규칙이 코드 비교로 돌려면 대표 3편이 PMID·등급·직접성·적용성 컬럼으로 테이블에 들어가야 함(세민 님 스키마 영역).
