# 고민 카테고리 정리

이 문서는 사용자 자연어 입력에서 추출할 표준 고민 태그를 정리한 팀원3 작업 문서입니다. 실제 태그 원천 데이터는 `data/tags.json`을 기준으로 합니다.

> MVP 단계 결정: 기존 15개 후보를 메인 10개 + 보조 1개로 통합 확정. 아토피는 별도 태그 없이 속건조의 동의어로 흡수, 모낭염은 신규 태그로 추가(보습·진정·항균 효능 연결), 다크서클은 보조 태그로 유지(low weight).

## 표준 고민 태그

> 백엔드 매칭 로직(`parser.py`)은 입력 텍스트에 `name` 또는 `synonyms` 문자열이 그대로 포함되는지만 검사하며, 복합 표시명("A/B")을 단어 단위로 쪼개 인식하지 않습니다. 그래서 `표시명`은 한 단어로 유지하고, 나머지 구성 단어는 `동의어`에 명시적으로 포함합니다.

| 메인 | 1 | `concern_acne` | 여드름 | 뾰루지, 농포, 턱드름 | 피지조절, 진정, 각질케어, 항균 | normal |
| 메인 | 2 | `concern_brightening_spots` | 미백 | 잡티, 기미, 주근깨, 색소침착, 다크스팟, 검버섯 | 미백/색소케어 | normal |

## 아토피·모낭염 처리 결정

- **아토피**: 별도 태그를 만들지 않고 `concern_dry_barrier`(속건조)의 동의어로 흡수합니다. 아토피성 가려움·진물 등은 결국 장벽 손상·보습 부족과 동일한 효능(보습, 장벽케어)으로 대응되기 때문입니다.
- **모낭염**: 신규 메인 태그 `concern_folliculitis`로 추가하고, 효능은 보습·진정·항균으로 연결합니다. 모낭염은 세균 감염성 염증이므로 항균 효능 매핑이 필요합니다.

## 태그 ID 규칙

- `tag_id`는 `concern_` 접두사를 사용합니다.
- 영문 소문자와 underscore만 사용합니다.
- 화면 표시명은 `name` 값을 사용합니다.
- 사용자가 입력할 수 있는 유사 표현은 `synonyms`에 누적합니다.

## 구분/weight 기준

- `구분`이 `메인`인 태그는 일반적인 점수 가중치로 반영합니다.
- `구분`이 `보조`인 태그(다크서클)는 보조 신호로 보고 `weight: low`를 적용합니다.

## 자연어 입력 해석 기준

- 하나의 입력에서 여러 고민이 감지되면 여러 `tag_id`를 함께 반환할 수 있습니다.
- 명확히 같은 의미의 표현은 기존 태그의 `synonyms`에 추가합니다.
- 의미가 겹치더라도 사용자가 기대하는 추천 효능이 다르면 별도 태그로 유지합니다. 예: `미백`과 `칙칙함`.

## unmatched_terms 기준

- 표준 고민 태그 중 어느 항목에도 매칭하기 어려운 입력은 `unmatched_terms` 후보로 둡니다.
- 제품 유형만 말한 표현은 고민 태그로 확정하지 않습니다. 예: 토너, 세럼, 크림.
- 피부 타입만 말한 표현은 고민 태그와 분리해 관리합니다. 예: 지성, 건성, 복합성.
- 증상이 너무 모호한 표현은 우선 보류합니다. 예: 피부가 이상함, 뭔가 안 좋음.
- 새 표현이 3회 이상 반복되거나 추천 품질에 영향을 주면 기존 태그의 `synonyms` 추가 또는 신규 태그 후보로 검토합니다.
